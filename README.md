## 🚀 Как использовать

### Добавление нового банка

1. Откройте `js/Bank.js`
2. Добавьте новый объект в массив `Banks`:

```javascript
{
    id: "mybank",
    name: "My Bank",
    icon: "image/banks/mybank.png",
    qr: "image/banks/mybank_qr.png",
    text: `Реквизиты:

Номер карты:
1234 **** **** ****

Получатель:
Toolgool`
}
```

3. Добавьте иконку и QR-код в папку `image/banks/`
4. Кнопка автоматически появится на сайте! 🎉

### Изменение аватара

Замените `image/IMG.png` на свое изображение (квадратное, рекомендуется 150x150px)

### Изменение Telegram ссылки

В файле `js/app.js` найдите строку:
```javascript
window.open('https://t.me/toolgool', '_blank');
```

Измените `toolgool` на ваш username.
